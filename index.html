核心功能

覆盖合同管理全流程

从合同录入到归档，每一个环节都经过精心设计，让合同管理更简单、更高效

合同批量录入与管理

支持手动录入、Excel模板批量导入、PDF扫描识别三种录入方式。合同全生命周期跟踪管理：草稿 → 执行中 → 完结/终止 → 归档，每个状态变更均留存操作记录。

  • PDF / Word 合同扫描自动识别字段
  • 合同变更、完结、终止、解除全流程
  • 多维度筛选：类型、状态、日期、客户
  • 删除保护：有关联资金/发票时禁止删除
核心模块

客户档案管理

系统根据合同内容自动提取并回填客户信息，统一管理甲方、乙方客户档案，支持快速查询和关联合同跳转。

  • 合同识别后自动创建/更新客户档案
  • 完整信息：纳税号、联系人、开户行账号
  • 多字段搜索：名称/联系人/电话/账号
  • 关联合同一键跳转查看

合同资金管理

精细化管理合同每笔款项，支持首笔款、进度款、尾款、质保金等多种款项性质，自动统计回款情况，及时预警逾期。

  • 款项性质分类：首笔/进度/尾款/质保金
  • 多账户管理：银行简称+账户后四位
  • 单条/Excel批量导入
  • 逾期预警 · 未回款自动提醒

发票管理

支持进项/销项发票分类管理，手动上传或邮件自动导入，系统自动读取发票信息并关联对应合同，消除人工对账工作量。

  • PDF / XML 发票自动识别关键字段
  • 进销项自动分类，关联合同自动匹配
  • 付款状态追踪：已付 / 未付
  • 申请开票工作流，审批留存记录

  • AI实时解析，人工0干预

  • 无法匹配时自动提醒管理员确认

智能特性

邮件自动关联发票

授权邮箱后，系统自动扫描收到的发票邮件，提取发票附件中的开票信息、金额、税率，并根据企业信息自动关联对应合同应开票记录。

  • 邮箱授权后全自动化处理
  • 支持增值税专票、普票多种类型
  • 不唯一时推送确认通知至管理员
  • 与资金管理联动，自动标记付款状态
